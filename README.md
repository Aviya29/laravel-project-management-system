# Laravel Project Management System

A Laravel-based web application created to practice full-stack web development, CRUD operations, database management, and the MVC architecture.

## 🚀 Features

- Create project records
- View project information
- Update existing projects
- Delete projects
- Store project data in a database
- Basic responsive user interface
- Laravel MVC architecture

## 🛠️ Tech Stack

- PHP
- Laravel
- MySQL
- JavaScript
- Bootstrap
- HTML
- CSS

## 🧱 Architecture

This project follows Laravel's MVC architecture:

- **Model** – Handles application data and database interaction
- **View** – Displays the user interface
- **Controller** – Handles requests and application logic
